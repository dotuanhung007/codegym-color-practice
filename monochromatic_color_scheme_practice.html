Cách 1: Nộp Bài Qua GitHub Repository (Khuyên Dùng)

Các bước đưa mã nguồn lên GitHub theo đúng yêu cầu nộp bài của CodeGym

  1. Tạo Repository Mới: Đăng nhập GitHub, nhấn nút New Repository. Đặt tên ví dụ: codegym-color-practice.
  2. Tạo File index.html: Trong repository, tạo file index.html và dán mã nguồn lấy ở Tab "3. Mã Nguồn HTML/CSS".
  3. Bật GitHub Pages (Tùy chọn xem web live): Vào Settings -> Pages, chọn Branch main và nhấn Save.
  4. Sao chép Link Nộp Bài: Sao chép đường link Repository GitHub (hoặc link GitHub Pages) và dán vào ô nộp bài của hệ thống CodeGym.
CP

Cách 2: Nộp Bài Qua CodePen (Nhanh Gọn)

Tạo bản demo chạy trực tiếp trên CodePen trong 1 phút

  1. Truy cập CodePen: Mở trang codepen.io/pen/.
  2. Dán Mã HTML: Dán toàn bộ mã nguồn HTML lấy từ Tab "3. Mã Nguồn HTML/CSS" vào khung HTML.
  3. Lưu & Đổi Tên Pen: Đặt tên Pen thành CodeGym Monochromatic Practice và nhấn Save.
  4. Dán Link Nộp Bài: Copy đường link CodePen từ thanh địa chỉ trình duyệt và dán vào trang nộp bài CodeGym.
